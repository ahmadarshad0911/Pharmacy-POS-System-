# Pharmacy POS System

A Point of Sale (POS) system designed for pharmacy management.

## Features

- **Product Management**: Add, update, and manage pharmacy inventory.
- **Cart & Checkout**: User-friendly interface for processing sales.
- **Receipt Printing**: Optimized receipt layout for thermal printers.
- **Responsive Design**: Accessible on various devices.

## Usage

Open `Pos System.html` in a web browser to launch the application.
